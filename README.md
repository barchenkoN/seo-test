# Массовая отправка жалоб через форму linkreclamatiogrwc.uk

Веб-инструмент, который полностью автоматически заполняет и отправляет форму
<https://linkreclamatiogrwc.uk/>: подставляет данные, решает reCAPTCHA через 2captcha,
отправляет и показывает результат по каждой строке.

## Запуск

Нужен ключ 2captcha. Создайте файл `.env` рядом с `docker-compose.yml` (или просто вставьте ключ в интерфейсе — появится поле, если ключ не найден):

```
TWOCAPTCHA_API_KEY=ваш_ключ
```

### Docker (одна команда)

```bash
docker compose up --build
```

### Без Docker (Python 3.10+)

```bash
pip install -r requirements.txt
python app.py
```

Откройте <http://localhost:8000>.

Ключ можно передать и без `.env`: `TWOCAPTCHA_API_KEY=ваш_ключ docker compose up --build`.

## Как пользоваться

1. Выберите **Submission Type**: Domain, IP или URL.
2. Вставьте цели, по одной на строку. Каждая строка отправляется отдельной заявкой.
   Строки с явно неверным форматом подсвечиваются сразу и не тратят капчу.
   Повторы (`Example.com` и `example.com.`, разные записи одного IPv6) убираются, чтобы не слать дубли жалоб.
   Под кнопкой видна оценка: сколько будет отправок, примерная стоимость капч и время.
3. Выберите **Threat Type**. Список берётся с самой формы, так что он не разойдётся с сайтом.
4. Заполните **Reason** и при необходимости приложите файл (JPG, JPEG, PNG или PDF, до 2 МБ).
   Один и тот же файл прикрепляется к каждой заявке.
5. Нажмите **Отправить**. В таблице справа видно, что происходит с каждой строкой:
   в очереди → загрузка формы → решение капчи → отправка → **отправлено (CF-XXXXXXXX)** или **ошибка + причина**.
6. Неудачные строки можно отправить повторно: по одной или все сразу («Повторить неудачные»).
   Перед повтором значение можно поправить прямо в таблице. Если сайт ответил ошибкой,
   рядом есть ссылка «ответ сайта» — сохранённый ответ сервера для разбора.
7. «Остановить» отменяет строки, которые ещё не начали отправляться (уже отправляемые завершатся).
   Отменённые строки потом можно отправить кнопкой «Повторить».
8. Коды можно скопировать (кнопка или клик по коду), результаты выгрузить в CSV —
   по одной отправке или все сразу («Все результаты (CSV)» вверху). Фильтр «только ошибки» помогает на больших списках.

Перед стартом проверяется баланс 2captcha: если денег не хватит на все капчи, отправка не начнётся.

История отправок хранится в `data/jobs.json` и не теряется при перезапуске. Лог работы пишется
в терминал и в `data/app.log`.
Строки, которые отправлялись в момент остановки, помечаются ошибкой, и их можно повторить.

## Как это работает

Браузер не нужен: форма обычная `multipart/form-data`, поэтому всё делается HTTP-запросами (`requests`).

Для каждой строки:

1. `GET /` в новой сессии. Сайт выдаёт cookie сессии и одноразовый `form_token`.
2. Форма разбирается из HTML, а не захардкожена: адрес отправки, скрытые поля, имена полей
   для каждого типа, варианты Threat Type, обязательный чекбокс условий, `data-sitekey` reCAPTCHA.
   Поля-ловушки (honeypot, например внутри `.hp`) отправляются пустыми, как у живого человека.
3. Через 2captcha (`RecaptchaV2TaskProxyless`) решается reCAPTCHA v2, и токен подставляется
   в `g-recaptcha-response`.
4. `POST /submit` с теми же полями, что отправил бы браузер (включая пустые поля скрытых типов
   и пустую часть файла, если файл не выбран), с `Referer` и `Origin`.
5. Из ответа извлекается код `CF-XXXXXXXX`. Если кода нет, берётся текст ошибки,
   который сайт показал бы пользователю (`.alert`, ошибки у полей).

### Повторы и ошибки

| Ситуация | Что делает инструмент |
|---|---|
| Сайт не принял капчу | Сообщает 2captcha о неверном решении (`reportIncorrect`, деньги возвращаются) и пробует снова |
| Сайт ограничивает запросы (429, «too many requests», Cloudflare) | **Все** потоки делают общую паузу (`THROTTLE_PAUSE`), затем повтор |
| Истёк токен формы/сессии, 5xx, сетевая ошибка до отправки | Автоповтор с новой сессией после паузы 5 с, 10 с… |
| 2captcha не решил капчу / нет свободных работников | Автоповтор |
| Неверный ключ 2captcha, нулевой баланс | Сразу ошибка, без повторов |
| Сайт отклонил данные (ошибка у поля) | Сразу ошибка с текстом сайта: повтор без исправления не поможет |
| Таймаут ответа **после** отправки | Ошибка «неизвестно, принята ли заявка», без автоповтора, чтобы не создать дубль |

Количество автоповторов задаётся `MAX_ATTEMPTS` (по умолчанию 3).

### Скорость

Одна отправка занимает 20–60 с, почти всё это время решается капча на стороне 2captcha.
Быстрее идёт пакет: строки отправляются параллельно (`CONCURRENCY`, по умолчанию 5).
Примерно: 100 строк ≈ 10 мин при 5 потоках и ≈ 6 мин при 10. Поднимать выше 10 стоит, только если
сайт не начинает ограничивать запросы (это видно в логе и в паузах в таблице).

## Настройки (переменные окружения / `.env`)

| Переменная | По умолчанию | |
|---|---|---|
| `TWOCAPTCHA_API_KEY` | — | ключ 2captcha (обязательно) |
| `TARGET_URL` | `https://linkreclamatiogrwc.uk/` | адрес формы |
| `CONCURRENCY` | `5` | сколько строк отправляется одновременно |
| `MAX_ATTEMPTS` | `3` | попыток на строку при временных ошибках |
| `MAX_TARGETS` | `1000` | максимум строк в одной отправке |
| `THROTTLE_PAUSE` | `30` | общая пауза (с), если сайт начал ограничивать запросы |
| `APP_PASSWORD` | — | пароль на интерфейс (логин любой). Нужен, если инструмент открыт не только на вашем компьютере: иначе любой может тратить баланс 2captcha |
| `CAPTCHA_TIMEOUT` | `180` | сколько секунд ждать решения капчи |
| `PORT` | `8000` | порт веб-интерфейса |

## Структура

```
app.py              веб-интерфейс и JSON API (Flask + waitress)
bot/submitter.py    разбор формы, отправка, разбор ответа, политика повторов
bot/captcha.py      клиент 2captcha (API v2)
bot/jobs.py         очередь, параллельная отправка, хранение результатов
bot/validation.py   проверка доменов/IP/URL и файла до отправки
templates/index.html  интерфейс оператора
tests/              тесты; mock_site.py — локальная копия формы + фейковый 2captcha
```

## Тесты

```bash
pip install pytest
python -m pytest -q
```

Тесты не ходят на реальный сайт и не тратят деньги 2captcha. Они поднимают локальную копию формы
(с сессионным токеном, honeypot и проверкой капчи) и фейковый 2captcha, а затем проверяют
пакетную отправку, все три типа, файл, повтор после отклонённой капчи, ручной повтор
с исправлением, дубликаты, проверку баланса, остановку (без двойной отправки после повтора),
паузу при лимите сайта, сохранение ответа сайта, пароль и фатальные ошибки ключа. Разбор формы дополнительно проверяется
на сохранённой копии настоящей страницы (`tests/fixtures/real_form.html`).

## API

- `POST /api/jobs` (multipart): `submission_type`, `targets`, `threat_type`, `reason`, `attachment`
- `GET /api/jobs`, `GET /api/jobs/<id>`, `GET /api/jobs/<id>.csv`
- `POST /api/jobs/<id>/retry` с JSON `{"idxs": [0, 2] | null, "edits": {"0": "new-value"}}`
- `POST /api/jobs/<id>/cancel` — остановить строки в очереди
- `GET /api/jobs/<id>/rows/<n>/response` — сохранённый ответ сайта на неудачную попытку
- `GET /api/export.csv` — все результаты
- `GET /api/balance` — баланс 2captcha
